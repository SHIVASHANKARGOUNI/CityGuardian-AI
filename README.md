## 📌 About the Project

**City Guardian AI** is an AI-powered smart-city solution designed to
**identify and monitor civic issues** to help improve:

- 🛡️ City Safety
- 🧹 Cleanliness
- 🏙️ Urban Management
- 📊 Civic Issue Monitoring
- ⚡ City Efficiency

The goal is to use **Artificial Intelligence and data-driven approaches**
to help cities identify problems and support better decision-making.

---

## 🎯 Problem Statement

Cities face various civic problems such as:

- 🚧 Infrastructure issues
- 🗑️ Waste and cleanliness problems
- 💡 Public-area issues
- 🛣️ Road-related problems
- 🏙️ Other civic concerns

Traditional reporting methods can make it difficult to identify,
track and monitor these issues efficiently.
